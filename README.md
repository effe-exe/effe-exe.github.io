# effe-exe.github.io

The web page of **Wardeye**, a free browser extension that names the cards on the table as you watch Riftbound streams on Twitch: **https://effe-exe.github.io**

The extension and its code live in [effe-exe/Wardeye](https://github.com/effe-exe/Wardeye).

- `index.html`: the whole page. No build step, no scripts, no trackers.
- `fonts/`: Space Grotesk, Inter and JetBrains Mono, under the SIL Open Font License 1.1 (`fonts/OFL-*.txt`).
- `lockup.svg`, `mark.svg` and `og.png`: Wardeye's logo and its image for link previews. The Wardeye name and logo are trademarks ([TRADEMARKS.md](https://github.com/effe-exe/Wardeye/blob/main/TRADEMARKS.md)).
